# 小小田园 SpatialFarm — 游戏设计文档 v0.4

> PICO Space Program 2026 参赛作品 · Spatial 空间应用创作赛道
> 一句话：把一座温馨的小岛村庄搬进你的客厅——种菜、吃饭、换鱼、做工具、防小偷，玩着玩着学会了真实的种植知识。

## 1. 愿景与定位

- **类型**：MR 空间村庄经营 + 生活模拟（cozy / 治愈系 / 轻生存）
- **情怀双杀**：QQ 农场「偷菜」的国民记忆 × 动森式温馨村庄人情味
- **科普灵魂**：每种作物按真实农艺规律生长，图鉴卡背面是真实种植知识
- **平台特性**：环绕用户的 360° 村庄、多窗口操作面板、手势照料、空间音频（海浪从码头方向传来）

## 2. 世界观与场景

玩家是清风岛上的一户农家，小岛自给自足、人人有事做。

```
            🏘️ 北：小镇主街（梅姨杂货铺 / 胖婶食堂 / 锤叔作坊）
 🌾 西：农田      ✨ 中央广场 ✨       🚢 东：码头（海叔的船）
    扩展区       （委托板 / 货车站）          （海浪声从这里传来）
            🏡 南：玩家小院 + 邻居老王家（要防偷！）
```

**家庭成员（四口）**：主角（开局选爸爸/妈妈，第一人称视角）+ 儿子小勇（可指派浇水，毛手毛脚会漏）+ 女儿小花（可指派除虫/采野果做小食，细心）。给孩子做饭提升亲密度 → 解锁更强的帮助能力。

## 3. 核心循环

```
🌅 早晨：查看作物（离线也在生长）→ 吃早饭 → 指派孩子今日任务
🌞 白天：照料农田 / 接委托 / 与海叔换鱼 / 下工匠订单 → 体力管理（吃小食）
🌆 傍晚：收获 → 菜筐搬上环岛货车（自动运出去卖）→ 给孩子做饭
🌙 夜晚：老王出没（防盗!）→ 睡觉存档 → 明天见
```

每周节奏：**周六集市日**（全员摆摊，收购价 ×1.3，村庄最热闹的一天）。

## 4. 系统设计

### 4.1 经济系统（玩法骨架）
- 初始资金 **5000 元**，钱包常驻显示
- **梅姨杂货铺**：卖种子（8 种分级定价）+日用品；也收蔬菜
- **锤叔作坊（工具树）**：口粮（南瓜）+ 材料费 → 制作工具；高级配方需等级解锁
- **蔬菜收购**：收购价>种子成本；品质 ★~★★★ → 价格 ×1.0 / ×1.5 / ×2.0；收购价随天气/时节小幅波动
- **田地**：初始 2 块免费，可扩至 8 块，价格 1000/2000/4000/8000/16000/32000

### 4.2 种植系统（科普灵魂）
- 播种（射线拖拽种子入田垄）→ 浇水/施肥/除虫（手势直接交互）→ 按真实阶段生长（发芽→幼苗→开花→结果，加速模拟 1 游戏日≈现实 10 分钟）→ 收获（粒子+音效庆祝）
- **照料决定品质**：浇水施肥及时 → ★★★；疏于照料 → 生虫、长势停滞
- 解锁图鉴卡牌，背面为真实种植知识（光照/水分/温度/农谚小贴士）

### 4.3 生存系统（温和压力）
- **饱食度进度条**：饿扁（红）→ 正常 → 吃饱 → 撑着了（干活体力消耗 +20%，有代价的贪吃）
- 每天自动消耗 3 餐；食物来源：自己的收成 / 换海叔的鱼 / 胖婶食堂买饭（¥80）
- **体力**：浇水/施肥/收获/搬筐都消耗；体力低动作变慢；快捷栏小食（饭团/烤红薯）随时补充
- 饿过头 → **生病卧床一天**（孩子代劳浇水但品质降）；极端 → 晕倒被家人抬回家（幽默过场，不死亡）

### 4.4 成长系统
- 经验：播种+2 / 浇水+1 / 收获+10×难度系数
- 等级解锁：Lv2 胡萝卜番茄 → Lv3 辣椒向日葵 → Lv4 草莓 → Lv5 南瓜；升级+体力上限，偶数级送免费扩田券

### 4.5 村庄 NPC（六家庭闭环）
| 家庭 | 职业 | 闭环角色 |
|---|---|---|
| 你 | 农夫 | 种菜→卖菜/换物→买种买工具→吃饭→升级 |
| 海叔 | 渔夫 | 2 蔬菜↔1 鲜鱼；台风天不出海鱼价涨 |
| 锤叔 | 工匠 | 收南瓜口粮+材料费制工具（含稻草人/看门狗） |
| 梅姨 | 杂货店主 | 卖种子日用品、收蔬菜 |
| 胖婶 | 食堂 | 卖饭恢复体力；每日菜谱收指定蔬菜价更高 |
| 老王 | 懒汉邻居 | 专职偷菜搞笑担当（防盗玩法核心） |

NPC 有作息时间（地图窗口可见）：出海、开店、午睡、赶集——**偷菜窗口=老王午睡时潜入他家院子**。

### 4.6 偷菜玩法（创新亮点）
- 走到老王/邻居院子，趁家中无人偷菜——被逮到罚款+好感下降
- 不做防护自家菜会被老王顺走 → 买稻草人（防鸟）/看门狗小黄（偷菜成功率减半）
- 猫鼠博弈的幽默感，不是恶性惩罚

### 4.7 任务与剧情（主线+支线，吸收自穿越题材设定）
- **广场委托板**：每日刷新 NPC 委托（「海叔想要 5 个番茄做沙拉」）→ 钱+好感度
- **主线六章**（新手指引+村庄成长史诗）：
  1. 新人上岛——认识村庄、种下第一株生菜
  2. 第一笔收获——卖菜赚钱、买第二块田
  3. 以物易物——和海叔换到第一条鱼，学会做饭
  4. 匠人之路——锤叔教你用工具，效率翻倍
  5. 台风之夜——天灾守护村庄（全员剧情事件）
  6. 丰收节——村庄大集，主角一家登上丰收榜
- **好感度剧情线**：每家 3 段小剧情（例：海叔的船坏了→资助南瓜→修好带你出海）
- **剧情对话窗口**：多窗口之一的对话框

### 4.8 物流与地图
- **环岛货车**：定时发车绕岛一圈；菜筐搬上车=自动运出岛卖（躺赚流），回程带来商店补给——村庄的「经济动脉」+视觉亮点
- **村庄地图窗口**：俯视小岛，房子图标+职业+各家作息状态，点击查看详情

### 4.9 视角
- 默认**第一人称**（MR 天然）；**观景模式**一键升空第三人称俯瞰全村，实时看到所有 NPC 活动（海叔出海、货车运菜、老王鬼鬼祟祟）——路演展示活村庄的王牌

## 6. 美术与音频

- **画风**：粉彩 Low-poly——Kenney/Quaternius 几何卡通基底 + 柔和粉彩调色板统一 + 圆润 UI；素材全 CC0（Kenney Food/Nature Kit、Quaternius、Poly Pizza），调色统一保证画风一致
- **音频**：空间音频——码头海浪（东）、小镇人声（北）、蛙鸣虫叫（夜）、浇水/收获/叮咚音效；BGM 轻快田园；素材 CC0（Freesound）
- **材质**：窗口用 Vibrant 玻璃材质贴合 PICO 系统风格

## 7. 技术架构

- Android + Kotlin + Jetpack Compose（**SpatialUI**：`com.pico.spatial.ui.*` + `PicoTheme`，禁用 Material）
- **Spatial BOM 6.2.8**；容器：主村庄用 **Stage**（Full Space 沉浸），商店/图鉴/地图/对话用 **WindowContainer** 多窗口
- **ECS**：植物（生长状态机 System）、NPC（作息/行为 System）、天气时间系统
- 模型：GLB（Kenney/Quaternius），`Entity.loadSuspend("asset://...")`；动画：补间（生长阶段切换）+ 骨骼（NPC/宠物）
- 交互：Collision + Interactable 组件；性能预算 90fps（low-poly、控制同屏实体）
- 数据驱动：经济数值/植物知识/剧情文案全部 JSON（`assets/data/`），改文案不改代码
- 开发工具链：pico-cli（build/emulator/capture/logcat/doctor）
