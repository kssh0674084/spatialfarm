# 🌱 小小田园 · 清风岛 — 游玩说明

> 版本：v0.9（2026-11-17）  
> 平台：PICO Spatial（Android / 全空间 Stage）  
> 类型：MR 空间田园经营 · 种植科普 · 轻喜剧偷菜

---

## 一、这是什么游戏

你住在一座叫「清风岛」的小岛上，屋前有几块田。  
种菜、浇水、收获、卖钱、扩田、升级，和岛上的邻居打交道——也包括那个总想顺走你菜的老王。

游戏把真实种植知识做进了图鉴：每种作物的光照、水分、温度、小窍门，都能在玩的时候顺手学会。

---

## 二、开始游戏

1. 在 PICO 设备上安装并启动《小小田园》。
2. 进入全空间后，正前方会出现欢迎面板，点 **「🌱 开始田园生活」**。
3. 建议先打开 **「☰ 菜单 → 🗺️ 地图 → 🏡 去村庄」**，熟悉一下田地和店铺。

> 首次进入的引导面板只看一次，之后可以在菜单里随时查看提示。

---

## 三、操作方式

| 操作 | 说明 |
|---|---|
| **移动** | 左摇杆，按头部朝向平滑移动（自动贴合地形） |
| **转视角** | 转头即可 |
| **交互 / 点击** | 手柄射线指向目标，扣扳机 |
| **打开菜单** | 看向右前方悬浮的 **「☰ 菜单」**，点一下 |
| **关闭窗口** | 点窗口右上角 **✕** |
| **面板跟随** | 菜单、欢迎页、田垄菜单都固定在视线前方，转头不会丢 |

> 在 PC 模拟器里：鼠标点击 = 扣扳机；模拟器没有摇杆，可用地图里的快速旅行移动。

## 四、60 秒上手

1. **☰ 菜单 → 🗺️ 地图 → 🏡 去村庄**
2. 走到田边，**点一块田** → 选种子 → 播种（Lv.1 可用生菜、小麦）
3. 再点田 → **💧 浇水**：加速生长，并提升品质
4. 等 1~2 分钟（游戏内时间已加速），田里出现 ✅ 表示成熟
5. 点田 → **🧺 收获**，作物进入篮子
6. 去 **胖婶·食堂**（点食堂房子或胖婶本人）卖出
7. 菜单 → **🪴 扩田**，用赚到的钱买下一块地

## 九、等级与经验

- 收获：每个作物 **+20 XP**
- 卖菜：每个作物 **+8 XP**
- 升级所需经验：`100 + (当前等级 - 1) × 80`
- 升级后会提示，并解锁更高价作物（见作物表）
- 菜单面板会显示 **Lv. 与经验进度**

---

## 十、每日内容

- **委托**：每天 3 条，按当天日期刷新。交付指定作物可获得 `收购价 × 数量 + 50` 的奖励。
- **图鉴**：每种作物第一次收获后解锁知识卡，背面是真实种植知识。
- **集市日**：每周六，胖婶收购价 ×1.3。

## 十一、地图、天气与沙盘

- **🗺️ 地图**：实时显示你的位置（红三角）与朝向；可快速旅行到：
  - 🏡 村庄
  - 🌊 湖边
  - 🛞 水车小屋
  - 🍃 风车丘
  - 🏖️ 海滩
- **🌧 天气**：菜单里可切换下雨 / 停雨。下雨时天空变灰，作物会自动补水并加速生长。
- **🔭 沙盘**：把村庄缩小成桌面模型，方便俯瞰全局（再点一次恢复）。

## 十二、偷菜与防偷

**老王偷你的菜**
- 老王每 40~70 秒出门一次，溜达到田边，偷走一块成熟作物。
- 有稻草人时，他只有 35% 概率得手；没有时 95%。
- **新手保护**：你累计收获不足 3 次时，老王不会下手。

**你偷老王的菜**
- 老王不在家时，点他家门口的菜筐 → 随机偷到南瓜或番茄。
- 老王在家时点菜筐 → 被逮到，罚款 ¥200（钱包不会变负数）。

## 十三、存档与重置

- 游戏每约 3 秒自动保存（钱包、田地、作物、等级、天气偏好、欢迎状态等）。
- 菜单 → **🗑 重置**：第一次点击变成「⚠️ 确认重置」，再点一次清空存档。
- 重置后建议重启应用，确保场景状态完全刷新。

## 十四、赚钱路线建议

1. **开局**：生菜（1 分钟回本）快速周转，攒第一桶金。
2. **Lv.2**：胡萝卜/番茄，单价更高。
3. **Lv.3**：西瓜/玉米/草莓，配合委托交付。
4. **Lv.4**：南瓜，单价最高，适合周六集市日集中卖。
5. **小技巧**
   - 品质 ≥ 60 多收 1 个，勤浇水很划算。
   - 周五晚上种南瓜，周六成熟直接 ×1.3 卖。
   - 下雨天不用浇水，作物自己长。
   - 每天先看委托，再决定种什么。

## 十五、常见问题

**Q：点不到田 / 店铺？**  
A：手柄射线要对准目标再扣扳机；距离太远时走近一点。

**Q：种子按钮显示 Lv.2 / Lv.3？**  
A：等级不够。先种低阶作物收获、卖菜攒经验。

**Q：菜一直不长？**  
A：需要现实时间（生菜约 1 分钟）；浇水/施肥可加速，雨天也会自动生长。

**Q：面板挡视线？**  
A：点面板右上角 ✕；面板会跟随视线，不会因为转头而消失。

**Q：摇杆没反应？**  
A：确认手柄已连接；模拟器没有摇杆，请用地图快速旅行。

**Q：被老王偷光了？**  
A：买稻草人；前 3 次收获前有新手保护。

**Q：画面卡顿？**  
A：重启应用；模拟器长时间运行后可能变慢，重启模拟器即可恢复。

## 十七、已知限制

- 目前为**单机**体验，无联网与排行榜。
- 角色为低模卡通风格，动作以待机/行走为主。
- 模拟器帧率低于真机；部分空间窗口在小屏幕上会重叠，可逐个关闭。
- AI 生成的模型与贴图已做移动端优化，近看细节有限。
